## 수업 흐름 개정 (2026-10-17 오후)

사용자 요청으로 "지도에 바로 던져지는" 구성을 8단계 24화면의 수업 흐름(설명·활동·자기 분석·쓰기 혼합, 차시 구분 없음)으로 재편했다. 활동 화면은 지도를 넓고 높게 두고 패널은 접힌 채 시작한다. 브라우저에서 확인한 것: 단계 표시줄·내레이션·설명 화면·활동 화면(과제 머리 + 끼워 넣은 지도 + 응답 입력)·그리기 화면의 다음 버튼 잠금·교사 콘솔의 단계 목록과 화면 넘김·모바일(375px) 셸. E2E는 새 흐름으로 다시 작성해 통과했다(교사 화면 넘김 → 학생 따라가기 → 제출 → 공개 → 자기 분석 → 화산·경계 카드 → 설명 → 새로고침 복구 → 보고서의 관찰 기록 포함).

## 측정하지 않았거나 검증하지 못한 것

- 프로덕션 Cloudflare 배포: 2026-10-17 `wrangler deploy`로 https://earth-expedition.sirlma.workers.dev 에 배포했다(80개 자산, Durable Object `RoomDO` 바인딩 적용). `/api/health` 200, 랜딩·SPA deep link 200, `/.dev.vars`는 SPA fallback(HTML)만 반환해 비밀 파일이 제공되지 않음을 확인했다. `TEACHER_SECRET` secret은 아직 설정하지 않아 탐사실 생성은 `noSecret`으로 거부된다(혼자 탐사는 동작). GitHub `sirlma111216-boop/hiearth`에 push했고 Actions 워크플로는 `CLOUDFLARE_API_TOKEN` secret이 추가되면 push마다 배포한다.
- Hibernation 실제 동작: workerd 로컬에서 알람·저장·복구는 확인했으나, 프로덕션에서의 장시간 휴면 후 복구는 미검증.
- 3D 성능 수치(fps): 측정 도구를 돌리지 않았다. 1440px 내장 브라우저에서 체감 지연 없이 회전·재생되었다. 저사양 30fps 목표는 미측정.
- 실제 터치 기기·펜: Playwright 마우스 이벤트와 내장 브라우저 모바일 에뮬레이션으로만 확인했다.
- 인쇄 PDF: 인쇄 CSS와 정적 지도 재렌더링을 구현했고 화면에서 지도·출처·선이 보이는 것을 확인했으나, 실제 PDF 파일 출력은 열어 보지 않았다.
- 대비 수치는 토큰 값으로 계산했고(DESIGN_SYSTEM.md), 자동 접근성 검사 도구는 돌리지 않았다.
- 40명 부하는 같은 기기에서 실행한 로컬 시뮬레이션이다. 실제 교실 네트워크·공공 API 부하는 시험하지 않았다(공공 API는 실행 중 피드 1종만 서버 캐시로 호출).
- 음원 파일 없음(사용자 제작 예정): 무음 처리와 설정 화면의 "파일 없음 · 무음" 표시만 확인.
