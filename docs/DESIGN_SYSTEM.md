# 디자인 시스템

분위기: 과학박물관의 디지털 아틀리에, 정교한 관측 기구, 고급 지도집. 장식은 탐구를 돕고 가장자리로 물러납니다. 네온·HUD·보라 그라데이션·이모지 아이콘·과장된 그림자를 쓰지 않습니다.

## 토큰 (`src/styles/base.css` `:root`)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| --bg | #07151E | 바탕 |
| --surface | #0D222C | 패널 |
| --raised | #14313B | 떠 있는 면 |
| --primary | #66D8C1 | 주요 버튼 면, 포커스, 판 경계 선 |
| --brass | #D2AF75 | 작은 강조, 수정 추론 선, 소제목 |
| --text | #F3F0E7 | 본문 |
| --muted | #A8BCC4 | 보조 (고대비 모드에서 #D3E0E5) |
| --danger | #F08E85 | 오류, 화산 삼각형 |

대비(실측, WCAG 상대 휘도 계산): text/bg 15.6:1, muted/bg 9.3:1, primary-ink(#06201F)/primary 10.2:1, brass/surface 7.1:1. 모두 AA 이상. 고대비 모드는 muted와 경계선 투명도를 올립니다.

지도 색은 용도가 겹치지 않습니다: 지진 #F2C57C(원), 화산 #F08E85(삼각형), 판 경계 #FF496C(굵은 붉은 실선과 반투명 테두리), 내 최초 선 흰 실선, 내 수정 선 #55CFFF(하늘색 점선), 다른 사람 선 회색 가는 선. 교사 화면에서도 최초·수정 레이어의 색과 선 종류를 유지하며 선택한 학생은 굵게 강조합니다. 지도 위의 다섯 레이어 버튼으로 각각 켜고 끄고, ‘지도만 보기’로 기록을 지우지 않고 베이스 지도만 볼 수 있습니다. 공개 전 자료의 접근 제한은 그대로 적용합니다.

## 타이포그래피

- Pretendard Variable(로컬 WOFF2, SIL OFL, `public/fonts/`). 본문 16px/1.65, 보조 13~14px, 버튼 16px(작은 버튼 14px).
- 랜딩 제목 `clamp(36px, 5.2vw, 84px)`, 자간 -0.035em, 짧은 줄. 모바일 36~46px.
- `word-break: keep-all`, `overflow-wrap: anywhere`, 숫자는 `.num`(tabular-nums).
- 영문 브랜드 "EARTH ATELIER"는 같은 서체에 0.2em 자간. 별도 디스플레이 서체는 추가하지 않았습니다(외부 글꼴 의존 없음).

## 버튼 (`.btn`)

primary(청록 면·짙은 글자) / secondary(어두운 면·밝은 테두리) / quiet(텍스트) / destructive(붉은 테두리). 높이 48px(sm 40, lg 54), 모바일 터치 44px 이상. 상태: hover(배경 6%), active(1px 하강), focus-visible(2px 청록 외곽선 + 3px 오프셋 이중 링), disabled(45% 불투명 + `title`로 이유), loading(폭 유지, 스피너). 마우스를 따라다니는 효과 없음.

## 레이아웃

- 상단 바 56px: 브랜드 / 현재 활동·연결 / 소리·설정.
- 작업 공간: 중앙 지도, 왼쪽 증거 서랍 340px, 오른쪽 추론 도구 340px, 아래 시간 컨트롤. 1280px 이하 300px, 900px 이하에서는 패널이 bottom sheet로 바뀌고 하단 탭(지도·증거·추론·안내)으로 하나씩 엽니다. 발표 모드는 패널·배너를 접고 지도가 화면의 65% 이상을 차지합니다.
- 랜딩: 이미지 한 장의 타이틀 장면 → 핵심 행동 3개(혼자 탐사 > 탐사실 입장 > 교사로 시작) → 장면 3개 → 자료 제공 기관·최근 자료 확인 상태. 허위 이용자 수·수상·추천 문구 없음.

## 모션

버튼 150ms, 패널 260ms, 증거 공개 750ms, 제출 강조 400ms, 지도 시점 이동 650~800ms, 랜딩 이미지 페이드 600ms. `prefers-reduced-motion`과 앱 설정(동작 줄이기) 모두 지원하며 즉시 전환으로 바뀝니다. 자동 회전·강제 인트로·흔들림 없음.

## 아이콘·로고

`src/ui/Icon.tsx`의 단색 선형 SVG(stroke 1.6)와 텍스트 라벨을 함께 씁니다. 로고는 코드 SVG(`src/ui/Logo.tsx`, `public/favicon.svg`).

## 랜딩 3D 지구 (`src/landing/`)

레이어: ① CSS 우주 배경(`.hero-space`, 오른쪽 위 따뜻한 빛) → ② 정적 이미지(`<picture>`, 먼저 표시) → ③ 3D 지구 캔버스(`.landing-globe`, 준비되면 900ms 페이드인·정적 이미지는 페이드아웃해 지구 중복 방지) → ④ 가독성 그라데이션(`.landing-hero::after`, 왼쪽 짙음→오른쪽 투명) → ⑤ HTML 제목·버튼.
조정 위치: `src/landing/globeScene.ts`의 `GLOBE_CONFIG` — 자전 주기(`rotationPeriodSec` 180초, 서→동), 초기 경도(127°, 한국·동아시아), 지구 지름/중심(`diameterOfHeight`, `center`, 데스크톱·모바일 구분), 조명(`sun` 오른쪽 위 고정, `fill` 밤 면 보조광, `ambient`, `exposure`), 대기(`atmosphere` 색·세기·두께), 텍스처 해상도·픽셀 비율 상한.
동작: 경과 시간 기반 회전, 화면 밖·탭 숨김 시 렌더 중지 후 같은 각도에서 재개, 동작 줄이기(OS 설정 또는 앱 설정 "배경 움직임")면 정지 상태로 한 번만 렌더, WebGL·텍스처 실패·컨텍스트 손실 시 정적 배경 유지, 언마운트 시 geometry·재질·텍스처·renderer 정리. 캔버스는 `aria-hidden`이며 포인터 이벤트를 받지 않는다(드래그·줌 없음).
