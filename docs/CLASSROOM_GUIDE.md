# 교사용 수업 운영 안내

## 수업 전 (5분)

1. 교사 기기에서 `/teach` → 활동 제목, 시작 지역(전 지구/태평양 중심/일본 주변/남아메리카 서안/대서양 중앙부), 참여 상한(기본 40), 보관 시간(최대 24시간), 모둠 목록을 정하고 교사 비밀 값을 입력해 탐사실을 만듭니다.
2. 대화상자에 나오는 **복구 코드**를 메모합니다(다른 기기에서 교사 화면을 열 때 필요, 학생과 공유 금지).
3. 대기실의 QR과 6자 코드를 화면에 띄웁니다. 학생은 QR을 찍거나 `/join`에서 코드와 별명만 입력합니다. 실명·학번은 받지 않습니다.
4. 소리는 교사 기기에서만 켜고 학생 기기는 무음으로 둡니다.

## 수업 흐름 (교사 화면 왼쪽 "활동 단계"를 순서대로 누릅니다)

| 단계 | 교사가 하는 일 | 학생 화면 |
| --- | --- | --- |
| 1 관찰 | 발표 모드로 지구본을 보여 주며 시간 재생. "어디에 집중되어 있나? 어떤 띠를 이루나?" | 자유롭게 회전·확대, 시간 재생, 점 선택 |
| 2 최초 추론 | 입장 잠금을 켜 두고 그리기 시간 제공(5~7분). 참가 현황의 "1" 표시로 제출 확인 | 그리기 모드에서 선 그리기 → 제출(제출 후 변경 불가) |
| 3 추론 공개 | "추론 일괄 공개"가 자동으로 켜짐. 두 학생을 눌러 **비교 강조**, "의견 겹침 강조"로 많이 고른 곳 확인. 별명 공개는 선택 | 모두의 선이 회색으로 겹쳐 보임 |
| 4 화산 증거 | 카드가 학생 화면에 뜸. "화산과 지진이 함께 나타나는 곳은?" | 화산 삼각형 추가, 증거 담기 |
| 5 수정 추론 | 수정 시간 제공. 최초 선은 그대로 남음 | 최초 추론이 복사된 초안을 고쳐 제출 |
| 6 경계 비교 | 판 경계 모형 공개. "겹치는 곳·어긋나는 곳·경계 밖 지진" | 레이어를 켜고 끄며 비교 |
| 7 설명 작성 | 증거를 인용해 쓰도록 안내. 입력 잠금으로 마감 | 설명·자료의 한계 작성 |
| 8 결과 정리 | 결과 탭에서 체크리스트 확인, CSV/JSON 내려받기 | 탐구 카드 보기·인쇄·PNG·JSON |

도구: "모두 이곳 보기"는 모든 학생 지도를 교사 위치로 이동시킵니다(학생에게 알림). "조건 공유"는 "교사 화면 따라가기"를 켠 학생에게만 적용됩니다. 입력 잠금/다시 열기, 입장 잠금, 참가자 내보내기, 모둠 지정·필터가 있습니다. 전체화면 발표는 Esc로 나옵니다.

## 평가 지원

결과 표의 체크리스트는 "관찰 근거가 있는가 / 화산 자료를 함께 고려했는가 / 설명을 수정했는가 / 한계를 적었는가"를 확인 가능한 값으로만 표시합니다. 설명의 과학적 정확도는 자동 판정하지 않으며 서열화하지 않습니다. 개별 보고서는 결과 표의 "열기"로 봅니다.

## 끝난 뒤

- 기록은 보관 시간(기본 24시간) 후 서버에서 자동 삭제됩니다. 그 전에 CSV/JSON을 내려받으세요.
- "탐사실 종료"는 제출을 막고, "삭제"는 즉시 지웁니다(영향 범위를 확인 창에 표시).
- 학생 기기의 기록은 별개입니다. 설정 → "이 기기 기록 지우기".

## 문제가 생기면

- 3D가 멈추거나 느리면 지도 왼쪽 위 버튼으로 2D 지도로 전환(자동 전환도 됩니다). 답변은 유지됩니다.
- 학생 연결이 끊기면 상단 상태가 "재연결 중"이 되고 제출은 "전송 대기"로 표시된 뒤 재연결 시 자동 전송됩니다. 새로고침하면 서버 기록으로 복구됩니다.
- 학생이 다른 기기로 바꾸면 이전 별명의 기록은 교사 화면에 남고, 새 별명으로 다시 입장합니다.
- 최근 자료(USGS 피드)를 못 받으면 "저장된 수업 자료 사용 중"으로 안내되며 수업은 계속됩니다.

## 과학적 범위 (수업 중 꼭 짚을 것)

지진은 대체로 판 경계 부근에 집중되지만 경계 밖에서도 일어납니다. 화산 목록은 지금 분화 중인 목록이 아닙니다. 지진·화산 자료의 기간이 다릅니다. 최근 지진이 없다고 안전한 곳이 아닙니다. 점 크기는 피해 범위가 아닙니다. 판 경계는 연구 모형이며 학생 선을 점수로 평가하지 않습니다. 재생은 관측 기록의 시간순 표시이지 예측이 아닙니다.

## 수업 화면 순서

교사 화면 가운데의 **이전/다음**으로 한 화면씩 넘기면 학생 화면이 따라옵니다. 옆 목록에서 단계 첫 화면으로 바로 갈 수도 있습니다. 차시 구분은 없으며, 수업 시간에 맞춰 어느 화면에서든 멈추고 다음 시간에 이어갑니다.

| 단계 | 화면 | 종류 |
| --- | --- | --- |
| 1 시작 | 흔들리는 지구(내레이션) · 오늘의 탐구 질문 | 도입 |
| 2 지진 자료 | 지진은 무엇일까 · 점 하나의 뜻 · 우리가 쓰는 자료 | 설명(건너뛰기 가능) |
| 3 관찰 | 전 지구 한눈에 · 시간 돌려 보기 · 가까이 보기 | 활동 + 관찰 메모 |
| 4 추론 | 선 긋는 방법 · 최초 추론 그리기 | 설명 + 활동(제출 필수) |
| 5 돌아보기 | 우리가 그린 선(공개) · 내 선 돌아보기 | 활동 + 자기 분석 |
| 6 화산·수정 | 화산은 어디에 · 화산 증거 열기(카드) · 지진과 겹쳐 보기 · 생각을 고치는 것은 실력 · 수정 추론 그리기 | 설명 + 활동(제출 필수) |
| 7 판의 경계 | 판과 경계 · 모형 열기(카드) · 내 선과 비교 | 설명 + 활동 + 자기 분석 |
| 8 설명·결론 | 나의 설명 · 자료의 한계 · 처음과 수정한 생각 · 탐구 카드 | 쓰기 + 정리 |

활동 화면의 "진행 팁"은 교사 화면에만 보입니다. 학생 응답(선택·메모)은 결과 탭의 보고서에 모입니다.
