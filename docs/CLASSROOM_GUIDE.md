# 교사용 수업 운영 안내

## 수업 준비

1. `/teach`에서 수업 이름을 적고 수업을 만듭니다. 별도의 발급 코드나 가입은 필요 없습니다. 지역·인원·보관 시간·모둠은 ‘수업 설정 변경’에서 바꿀 수 있습니다.
2. 생성한 브라우저에 수업 관리 권한이 저장됩니다. 한 번 표시되는 복구 코드는 다른 기기에서 관리할 때 필요하므로 따로 보관하고 학생에게 공유하지 않습니다.
3. ‘학생 입장’의 QR 또는 링크를 공유합니다. 링크로 들어온 학생은 별명을 입력합니다. 직접 들어오면 6자리 수업 코드도 입력합니다.
4. ‘관찰 시작하기’를 누릅니다.

## 수업 진행

상단에는 네 구간(살펴보기 → 그려보기 → 증거로 다시 보기 → 정리하기)이 표시됩니다. 실제 활동 화면은 여섯 개입니다. 교사는 화면 아래 버튼으로 다음 활동을 열고, 학생 화면은 자동으로 따라갑니다.

| 화면 | 교사 | 학생 |
| --- | --- | --- |
| 지진 관찰 | 분포를 함께 살펴보고 다음 활동 열기 | 지도 이동·확대·점 선택 |
| 첫 생각 그리기 | 제출 인원 확인. 필요하면 ‘우리 반 선 함께 보기’ | 지도 위치를 정한 뒤 ‘선 그리기’. 제출한 첫 선은 보존 |
| 화산을 보고 수정하기 | 화산 자료를 보여주고 다시 생각할 시간 제공 | 첫 선을 바탕으로 수정. 그대로 유지해도 제출 |
| 판 경계와 비교하기 | 수정 제출 후 판 경계 공개 | 내 선과 모형의 공통점·차이 관찰 |
| 설명하기 | 근거를 들어 설명하도록 안내 | 설명과 자료의 한계를 같은 화면에서 쓰고 저장 |
| 탐구 카드 | 결과 탭에서 기록 확인 | 처음·수정한 선과 설명 확인, 카드 인쇄·저장 |

제출하지 않은 학생이 있는 상태에서 다음 활동을 열면 확인창이 나옵니다. 학생은 이전 활동을 다시 볼 수 있고 ‘현재 수업으로 돌아가기’로 복귀합니다. 다음 활동을 여는 일은 교사가 맡습니다.

지도 아래에 그리기 도구가 있습니다. 추가 편집은 ‘선 편집’, 지도·자료 선택은 ‘보기·자료 설정’에 모았습니다. 교사의 ‘학생 지도도 이곳으로’는 학생 지도를 교사가 보는 위치로 이동시킵니다.

학생별 제출 현황과 수업 관리 항목은 필요할 때 펼칩니다. 입장·입력 잠금, 모둠 관리, 내보내기, 수업 종료·삭제는 ‘수업 관리’에 있습니다.

## 종료와 복구

- 기록은 정한 보관 시간(최대 24시간) 후 서버에서 삭제됩니다. 필요한 결과는 그 전에 내려받습니다.
- 다른 브라우저에서는 수업 만들기 화면의 복구 항목에 수업 코드와 복구 코드를 입력합니다.
- 연결이 끊긴 선 제출은 전송 대기로 표시되고 재연결 시 전송됩니다. 설명은 저장 완료 표시를 확인합니다.
- 3D가 느리면 ‘보기·자료 설정’에서 2D로 전환합니다. 기본 보기는 2D입니다.
- 혼자 탐사는 같은 여섯 화면을 스스로 진행합니다. 첫 선·수정 선 제출, 설명 저장 후 다음으로 넘어갑니다.

## 자료를 읽을 때

지진은 대체로 판 경계 부근에 집중되지만 경계 밖에서도 일어납니다. 화산 목록은 현재 분화 중인 목록이 아닙니다. 지진과 화산 자료의 기간은 다릅니다. 최근 지진이 없다고 안전한 곳은 아닙니다. 점 크기는 피해 범위가 아닙니다. 판 경계는 연구 모형이며 학생 선을 점수로 평가하지 않습니다. 재생은 관측 기록을 시간순으로 보여주는 것이며 예측이 아닙니다.
